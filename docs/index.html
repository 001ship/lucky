Lucky

any 出品的 LLM 多智能体自主安全测试平台 · 选一种方式,几分钟跑起来

一键部署

Render 最快 自动带 PostgreSQL

点下面的按钮，Render 读取仓库里的 render.yaml，自动创建 Web 服务与托管数据库并注入连接串。

Deploy to Render →

Linux / macOS Docker

一条命令：拉源码、随机化数据库密码、起容器、等就绪、打印初始化令牌。

curl -fsSL https://raw.githubusercontent.com/001ship/lucky/main/install.sh | sh

Windows PowerShell

装了 Docker Desktop 用这条；已有 PostgreSQL 就在后面加 -Native -PgHost … -PgPassword …。

irm https://raw.githubusercontent.com/001ship/lucky/main/install.ps1 | iex

容器镜像 amd64 + arm64

公开镜像，无需登录即可拉取。

docker run -d --name lucky -p 8787:8787 \
  -e ARTEX_PG_DSN='postgres://user:pass@host:5432/lucky?sslmode=disable' \
  -v lucky-data:/app/data ghcr.io/001ship/lucky:latest

直接下载

Linux / macOS / Windows 单二进制，前端已内嵌，解压即用。

打开 Releases → 源码仓库

部署之后

  1. 打开 http://127.0.0.1:8787（云平台用分配的域名）
  2. 首次进 /setup，用日志里的 Setup token 设置管理员密码
  3. 登录账号名固定为 Lucky，密码是你刚设的那个
  4. 到「系统配置 → LLM」填模型 Key，建第一个任务

接 Agent

MCP 服务端 11 个工具

在「系统配置 → MCP」开启并创建访问令牌后，外部智能体可通过 Streamable HTTP 接入：建任务、查进度、读漏洞、补充提示。

POST http://<host>:8787/mcp
Authorization: Bearer artex_mcp_<你的令牌>
