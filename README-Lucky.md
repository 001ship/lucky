# Lucky

**any 出品的 LLM 多智能体自主安全测试平台。**

Lucky 用一组协作的语言模型智能体把「信息收集 → 漏洞验证 → 利用链推进 → 报告交付」串成自动闭环：
规划者（planner）读态势、派意图；执行者（worker）用真实工具跑每一步并把资产、事实、漏洞写回图谱；
所有动作留痕进流量代理与审计记录，任何时候都能人工介入。

---

## 核心能力

| 模块 | 说明 |
|---|---|
| **双图态势** | 资产图（跨任务共享的资产真值库）+ 探索图（单任务的血缘推进链），用锚点互相索引，可看「某个资产被哪些意图测过」 |
| **多智能体编排** | planner 持有跨轮次共享 todolist，按依赖逐步派发，让多步利用链不重复、不错序 |
| **人在环路** | 对话页随时下达指令、暂停、接管；审批门（intercept）可对高危工具调用逐条放行或拦截 |
| **流量证据** | 内置记录型 MITM 代理，每条发现可回溯到原始 HTTP 报文，支持 Burp 式重放与批量重发 |
| **漏洞复测** | 独立 retester 智能体，三态结论（仍可复现 / 已修复 / 无法确认）自动回写漏洞状态 |
| **报告交付** | 任务与跨任务报告、按严重度归并的漏洞文件夹、CSV 导出 |
| **MCP 服务端** | 外部智能体可经 MCP 连接本平台：查任务、建任务、暂停恢复，令牌带 scope 与来源白名单 |
| **多模型** | 按 LLM 配置分配并发 Worker 池，支持 OpenAI 兼容端点、Anthropic、本地 Ollama |
| **成本与止损** | Token 用量按模型统计；「无成果止损」按运行时长与独立漏洞数自动收尾 |

## 界面

- **主题**：中性灰白 + 近黑主色（`#171717`）、1px 细边框、0.5rem 圆角，浅/深色一键切换
- **品牌**：产品名、Logo、favicon、页面标题由 `web/src/config/app-config.ts` 单点控制
- **语言**：中文 / English（由服务端 `output_language` 设置驱动）

## 部署（Windows）

```powershell
# 1) 目录结构
lucky\
  lucky.exe            # 单二进制（前端已内嵌）
  config.json          # 数据库连接
  skills\              # 技能包
  data\                # 会话、转录、流量等文件产物
  start.bat            # 守护启动（崩溃退避重启）

# 2) config.json
{
  "database": {
    "host": "127.0.0.1", "port": 5433,
    "user": "artex", "password": "<你的密码>",
    "dbname": "artex", "sslmode": "disable"
  },
  "skill_dir": "C:\\path\\to\\lucky\\skills"
}

# 3) 启动
.\start.bat          # 默认监听 127.0.0.1:8787，流量代理 127.0.0.1:8788
```

首次访问 `http://127.0.0.1:8787` 进入 `/setup` 初始化登录密码，账号名为 **Lucky**。
